# Library SQL Query Project (MySQL)

## 📌 Project Overview
This project demonstrates SQL querying and reporting skills using a realistic library books dataset.

It focuses on:
- Extracting data using SELECT queries
- Filtering and sorting results
- Using DISTINCT and aliasing
- Creating reusable SQL views
- Simulating real-world reporting
